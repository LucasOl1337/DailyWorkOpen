# LucasOL workspace

Personal workspace the DailyWork app reads. Name is historical. Put **your**
files here; the copies in this repository are empty templates.

| Path | Role |
| --- | --- |
| `Knowledge/` | Canonical notes projected on Principal |
| `Portfolio/` | CVs, campaign files, public assets |
| `Workspace/` | Operational memory of projects |
| `Research/` | Notes not yet promoted |
| `Private/` | Sensitive runtime, gitignored |

Copy `Portfolio/privacidade/dados-candidatura-canonicos.example.md` to
`dados-candidatura-canonicos.local.md` and fill it. Replace the placeholder
PDFs in `Portfolio/curriculos/ativos/`.
