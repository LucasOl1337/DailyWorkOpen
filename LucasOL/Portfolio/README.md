# Portfolio

Put professional material the app is allowed to read.

- `curriculos/ativos/` — the two official CVs (AI + Software, PT/EN)
- `privacidade/` — form facts used by candidacy missions (local file, gitignored)
- `empresas/<id>/` — campaign findings, playbook, targets
- `jobs/` — optional legacy application log
- `assets/publicaveis/` — images the editorial pipeline may attach
