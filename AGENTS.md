# Repository contract

This is the public DailyWork checkout. Decide, implement, test and document
without extra approval steps. Do not commit secrets, tokens, OTPs, private
attachments or `.env` files.

1. Keep unrelated local changes out of your commit.
2. Use fixtures in tests; never a production vault or a personal browser profile.
3. Read [INDEX.md](./INDEX.md) before opening a new area of the tree.

Candidacies: if a mission needs a CV, follow [docs/carreira.md](./docs/carreira.md)
and the files in `LucasOL/Portfolio/curriculos/ativos/`.
